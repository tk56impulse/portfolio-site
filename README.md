# My Portfolio

制作物の紹介、プロフィール、連絡先をまとめたポートフォリオサイトです。

## 🌐 公開URL
[ポートフォリオを見る](https://portfolio-site-bay-one.vercel.app/)

---

## 🧠 概要
未経験からエンジニア転職を目指し、学習および個人開発の成果をまとめたサイトです。  
課題解決を意識したアプリ開発と、その背景・改善プロセスを重視して構成しています。

---

## 🛠 主な内容
- Projects（制作物）
- About（プロフィール・スキル）
- Contact（連絡先）

---

## 💻 使用技術
- React
- Vite
- CSS
